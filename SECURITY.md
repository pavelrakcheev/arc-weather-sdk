# Безопасность

## Поддерживаемые версии

| Версия | Поддержка |
| --- | --- |
| 1.0.x | Да |
| < 1.0 | Нет |

## Как сообщить об уязвимости

Не публикуйте детали уязвимости в открытом issue. Используйте приватное сообщение через
[GitHub Security Advisories](https://github.com/pavelrakcheev/arc-weather-sdk/security/advisories/new)
или напишите на `275796770+pavelrakcheev@users.noreply.github.com`.

Опишите затронутую версию, шаги воспроизведения и ожидаемое поведение. Ответ приходит по
электронной почте. Исправление выпускается новой версией, а уязвимость описывается в
[CHANGELOG.md](CHANGELOG.md).

## Ключи API

Ключ Arc Weather API — секрет. Не публикуйте его в репозиториях, логах и сообщениях об
ошибках. Передавайте ключ через переменную окружения `ARC_WEATHER_API_KEY` или через
настройки приложения, а не через аргументы командной строки в общем доступе.

Если ключ скомпрометирован, отзовите его и выпустите новый.
