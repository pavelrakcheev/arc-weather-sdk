# Справочник Arc Weather API

Базовый адрес задаётся при создании клиента. По умолчанию — `https://api.arcweather.dev`.
Все ответы — JSON.

## Аутентификация

Каждый запрос кроме `/v1/health` требует заголовка `X-API-Key`.

| Код | Причина |
| --- | --- |
| `401` | Ключ не передан или неизвестен |
| `403` | Ключ не допущен к этой операции |

## Квоты

У каждого ключа есть лимиты запросов в минуту и в сутки, заданные планом подписки.
Ответ содержит заголовки:

| Заголовок | Значение |
| --- | --- |
| `X-RateLimit-Limit` | Сколько запросов разрешено в текущем окне |
| `X-RateLimit-Remaining` | Сколько запросов осталось |
| `X-RateLimit-Reset` | Через сколько секунд окно сдвинется |

При превышении API отвечает `429` и добавляет `Retry-After` в секундах.

## Формат ответа

Каждая операция возвращает единый конверт:

```json
{
  "module": "sinoptic",
  "operation": "forecast",
  "status": "partial",
  "items": [
    {
      "type": "forecast",
      "module": "sinoptic",
      "source": "Open-Meteo",
      "valid_at": "2026-11-10T10:00:00+10:00",
      "fetched_at": "2026-11-10T09:58:11+10:00",
      "timezone": "Asia/Vladivostok",
      "current": {"temperature": 4.2, "weather_code": 3},
      "daily": [{"date": "2026-11-10", "min": 1.1, "max": 6.4, "precipitation": 20}],
      "source_url": "https://open-meteo.com/",
      "license_url": "https://open-meteo.com/en/terms",
      "stale": false
    },
    {"type": "unavailable", "module": "sinoptic", "source": "MET Norway"}
  ]
}
```

Тип элемента задан полем `type`:

| `type` | Модель SDK |
| --- | --- |
| `forecast` | `Forecast` |
| `source-data` | `SourceData` |
| `planetary-data` | `PlanetaryData` |
| `unavailable` | `SourceUnavailable` |

Статусы конверта:

| Статус | Значение |
| --- | --- |
| `ok` | Есть данные |
| `empty` | Источник ответил, но выборка пуста |
| `partial` | Часть источников недоступна |
| `unavailable` | Недоступны все источники операции |

## Эндпоинты

### `GET /v1/forecast`

Прогноз по точке.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `lat` | float | Широта, от −90 до 90 |
| `lon` | float | Долгота, от −180 до 180 |
| `days` | int | От 1 до 3, по умолчанию 1 |

### `GET /v1/city`

Городская сводка. Элемент результата — словарь с полями `city`, `country`, `timezone`,
`current`, `daily`, `source`, `source_url`, `license_url`, `valid_at`, `fetched_at` и `stale`.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `name` | str | Название города |
| `days` | int | От 1 до 3, по умолчанию 1 |

### `GET /v1/region`

Наблюдения, предупреждения и архивы по области.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `module` | str | Модуль операции, по умолчанию `sinoptic` |
| `operation` | str | Имя операции, по умолчанию `metar` |
| `preset` | str | Имя готового профиля: `moscow`, `moscow-oblast`, `sochi-adler`, `primorye` |
| `lat`, `lon` | float | Центральная точка, если она отличается от профиля |
| `west`, `south`, `east`, `north` | float | Границы области для произвольной территории |
| `airports` | str | Коды аэропортов через запятую |
| `stations` | str | Идентификаторы станций через запятую |
| `areas` | str | Названия областей оповещений через запятую |
| `archive_day` | str | Дата архива в формате `YYYY-MM-DD` |

### `GET /v1/planet`

Архив планетарной миссии.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `planet` | str | `mars`, `venus` или `titan` |
| `sol` | int | Номер солн. Поддерживается для `mars` |
| `limit` | int | Число строк или файлов, по умолчанию 100 |

### `POST /v1/query`

Любая операция каталога по имени. Тело запроса:

```json
{"module": "sinoptic", "operation": "city-forecast", "request": {"city": "Владивосток", "days": 2}}
```

### `GET /v1/modules`

Каталог модулей и операций со списком источников.

### `GET /v1/health`

Проверка живости сервиса. Ключ не требуется.

## Коды ошибок

| Код | Значение |
| --- | --- |
| `400` | Некорректные параметры запроса |
| `401` | Ключ не передан или неизвестен |
| `403` | Нет доступа к операции |
| `404` | Ресурс не найден |
| `422` | Тело запроса не прошло проверку |
| `429` | Превышена квота |
| `500` | Внутренняя ошибка сервиса |
| `503` | Источники данных временно недоступны |

Тело ошибки — объект с полем `detail`.
